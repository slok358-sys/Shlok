# Shlok Pandey - Creative Portfolio

A premium, high-performance portfolio website built with modern web technologies. This project features immersive UI/UX, smooth GSAP-like animations (vanilla JS), and a sleek dark-mode aesthetic with glassmorphism.

## 🚀 Features
- **Dynamic Mesh Background**: Animated gradients for a deep, cinematic feel.
- **Magnetic Cursor**: Interactive custom cursor follower.
- **Scroll Reveal**: Sections animate into view as you scroll.
- **Bento Grid About Section**: Modern layout for a professional biography.
- **Tech Stack Grid**: Detailed technical expertise with animated tags.
- **Responsive Design**: Optimized for desktop, tablet, and mobile.

## 🛠️ Tech Stack
- **Structure**: HTML5
- **Styling**: Vanilla CSS3 (Custom Variables, Flexbox, Grid)
- **Logic**: Vanilla JavaScript (Intersection Observer API)
- **Typography**: Google Fonts (Outfit & Inter)

## 📂 Project Structure
- `index.html` - Home Page
- `about.html` - Professional Biography
- `skills.html` - Technical Arsenal
- `work.html` - Portfolio Gallery
- `contact.html` - Inquiry Form
- `style.css` - Global Styles & Animations
- `script.js` - Interactive Logic

## 🔧 Installation
Simply clone the repository and open `index.html` in your browser.
```bash
git clone <your-repo-url>
```

## 📸 Personalization
To use your own photo, replace `profile.jpg` in the root directory with your portrait.
